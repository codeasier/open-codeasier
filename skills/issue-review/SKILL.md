# Issue Review

Require exactly one issue number. Read the complete issue, repository context, relevant code, documentation, tests, and API contracts before judging it. Distinguish whether the reported problem exists, whether the proposed change is reasonable, and the correct boundary when it is only partly reasonable. Draft a concise evidence-based comment, show it to the user, and post it only after explicit confirmation. Do not modify source code.
