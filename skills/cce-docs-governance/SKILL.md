# Documentation Governance

Accept `audit` or `fix` and an optional scope; default to repository-wide audit. Read the README, documentation indexes, package metadata, CLI entry points, and other factual sources. Check README weight, navigation, broken relative links and anchors, language consistency, and claims against implemented behavior. In audit mode, report findings without edits. In fix mode, make low-risk factual and link corrections; request confirmation before restructuring, deleting, renaming, or changing externally referenced paths. Report mode, findings, edits, and deferred structural work.
